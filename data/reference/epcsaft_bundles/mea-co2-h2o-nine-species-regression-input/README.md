# MEA nine-species regression input

Version `1` is an immutable, user-provided ePC-SAFT input bundle for the
reduced MEA tracer at 313.15 K and 6,105.45–300,000 Pa.

The parameter rows preserve the provenance and limitations of the retained
MEA evaluation records. The MEAH+ and MEACOO- active values are regression
starts, not accepted parameters. Other transferred values remain fixed inputs
with their row-level limitations. Loading this bundle does not add it to the
Provider catalog or establish predictive validity.

The sibling `1.receipt.json` records the exact installed wheel and public
native-header evidence. It distinguishes input executability from scientific
acceptance and proves inside-domain success and outside-domain failure without
binding a Provider source checkout.

The earlier `mea-co2-h2o-nine-species-diagnostic/1` bundle remains unchanged.
